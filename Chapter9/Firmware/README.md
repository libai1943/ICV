# Chapter 9: experimental-vehicle firmware

This directory contains the vehicle firmware supplied by Yueshuo Sun for the experimental platform. The initial firmware and integration work are credited to Yueshuo Sun.

- Book repository: https://github.com/libai1943/ICV

## Contents

The Arduino sketch is `main/main.ino`; the supplied SSD1306 display library is in `libraries/SSD1306`. Install the remaining libraries named by the sketch as described in the chapter README. Pin assignments, timing, framing, and calibration parameters are defined in the sketch. Library attribution and license notices remain in the supplied files.
